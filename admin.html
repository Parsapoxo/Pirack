Leaderboard

⚠️ Sign-in passwords are stored in plain text in leaderboard.json since this is a static site with no server — anyone technical can see them via browser dev tools. Don't reuse a real password here.

Prize is the player's total earned amount. What they can spend is shown below it as Available = Prize − Spent: purchases (titles, banners, avatars, personal-photo uploads) are subtracted automatically and never change the Prize number you type here.

Announcements (bell icon)

Every announcement stays in the history behind the bell, newest first, with a "published X ago" note. Blinking: a red dot shows on the bell until the visitor opens it. Normal: no red dot, but the announcement is still listed. Deleting removes it from the history. Click the main Save button to publish.

Wallpapers

Upload an image or short looping video. It'll show up as an option for everyone in the site's wallpaper menu.

Banners

Create a category (e.g. "Halloween"), then add banners inside it. Each banner is a PNG or GIF, always shown at a 5:1 ratio on the site regardless of the source shape. Color picks are limited to the same 5 tiers used for Player Titles.

Avatars

Create a category, then add ready-made avatars inside it (always shown as a square 1:1). Color picks are limited to the same 5 tiers used for Player Titles. This is separate from a player's own photo upload (which costs 💎 1500 Prize and needs your approval).

Avatar Requests

When a signed-in player changes their profile picture on the site, it shows up here as a request instead of being applied automatically. Approve it to actually push it live, or reject it to discard.
